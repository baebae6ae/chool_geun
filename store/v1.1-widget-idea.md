# v1.1 아이디어: 홈 화면 위젯 (Android)

목업: `store/widget-mockups/` (1-working, 2-overtime, 3-done)

## 원칙
- 위젯은 앱의 상태를 **보여주기만** 한다. 야근 시작·진짜 퇴근·퇴근 시각 기록 같은 결정은 전부 앱에서만.
- 위젯을 누르면 **항상 앱이 열린다.** 위젯 안에서 쓰다듬기 같은 상호작용은 하지 않는다.
- 애니메이션 없음. 그림은 상태가 바뀔 때만 바뀌는 정지 그림 (하루 10번 남짓 갱신) → 배터리 부담 최소.
- Android 전용 (iOS는 네이티브 앱이 따로 필요).

## 크기
- 작게 2×2: 캐릭터 + 카운트다운 + 한 줄 상태
- 가로 4×1: 캐릭터 + 카운트다운 + 오늘 번 돈(기준 시각·분당 금액) + 하루 진행 막대

## 상태별 화면
| 상태 | 위젯 |
|---|---|
| 출근 전 | 자는 캐릭터 + "출근까지 0:42:10" |
| 근무 중 | 시간대별 자세(출근 직후 졸림 / 오전 열일 / 점심 / 오후 멍 / 퇴근 30분 전 신남) + "퇴근까지 3:12:41" + 진행 막대 |
| 퇴근 시각 지남 (야근 안 함) | "퇴근 완료" 밤 배경 + 자는 캐릭터 + 오늘 번 돈 + 월급날 D-day |
| **앱에서 야근하기를 누름** | 썩어가는 방 + 죽상 캐릭터 + "야근 2:23:41"(올라감) + 벌었어야 할 돈(또는 야근수당) + "분당 ₩453 날리는 중" |
| 앱에서 진짜 퇴근 | 다시 "퇴근 완료" |
| 쉬는 날 | 쉬는 캐릭터 + 월급날 D-day |

## 야근 모드
- 시작/끝은 앱에서만. 앱이 야근하기·진짜 퇴근을 누르는 순간 위젯을 즉시 갱신한다.
- 야근 30분·1시간·2시간·3시간째마다 방이 한 단계씩 더 썩는다 (정해진 시각에만 갱신).
- 자정이 되면 앱과 같은 규칙으로 야근 종료 → 위젯도 원래대로.

## 숫자 표시
- 카운트다운(퇴근까지/야근 경과)은 Android 기본 Chronometer로 초 단위로 흐름 (위젯이 직접 갱신하지 않음).
- 오늘 번 돈은 실시간이 아니므로 "14:47 기준 · 분당 ₩302"처럼 기준 시각과 분당 금액을 함께 보여준다. 정확한 금액은 앱에서 촤르르.

## 구현 메모
- Kotlin AppWidgetProvider + RemoteViews (Capacitor 앱 안의 네이티브 모듈).
- 앱을 열 때마다 앞으로 2주 치 출퇴근 시각·공휴일·시급·캐릭터·꾸미기를 SharedPreferences로 넘겨 두고, 상태 전환 시각마다 AlarmManager로 위젯 갱신 예약 → 앱을 며칠 안 열어도 위젯이 맞게 돈다.
- 야근 시작/종료는 앱 → 네이티브 브리지로 즉시 갱신 요청.
- 캐릭터 그림은 지금 SVG 스프라이트에서 PNG로 뽑아 리소스에 넣는다 (4종 × 시간대별 자세 × 야근 썩음 단계).
- 확인 필요: 앱 → 위젯 즉시 갱신 연결, 기기별 알람 정확도(정확 알람 권한 없이 가능한지), 잠금화면 진행 중 알림은 v1.2 후보.
