# 🐹 햄스터 출근일지

> 출근해서 켜두면, 햄스터가 내가 일한 시간만큼 무언가를 만들고 퇴근할 때 하나가 완성되는 앱.

모바일 우선 **PWA** (React + TypeScript + Vite). 휴대폰 브라우저에서 열고 "홈 화면에 추가"하면 앱처럼 설치되고 오프라인에서도 동작합니다. 모든 데이터는 기기(localStorage)에만 저장됩니다.

## 실행

```bash
npm install
npm run dev        # 개발 서버
npm test           # 도메인 로직 테스트 (vitest)
npm run build      # 타입체크 + 프로덕션 빌드 → dist/
npm run preview    # 빌드 결과 미리보기
```

시연용으로 URL에 `?t=2026-09-22T17:42` 를 붙이면 그 시각부터 시간이 흐릅니다 (예: `?t=2026-09-22T17:59:50` → 퇴근 연출).

| 12~13. 주간·월간 | 이번 주 MON~FRI, 주차별 결과물, 월간 요약 + 사무실 |
| 14. 설정 | 월급, 급여일, 출퇴근·점심 시간 / 월 근무일수, 주말 근무, 햄스터 이름 |

## 동작 규칙

- **실제 시간 기준**: 진행률·번 돈·가챠·퇴근은 모두 현재 시각으로 계산합니다(`src/domain/engine.ts`의 `reconcile`). 앱을 닫아 둬도 다음에 열면 그동안의 가챠와 퇴근이 한 번에 반영됩니다.
- **하루 기록**은 근무일에 앱을 처음 연 날에 생성됩니다. 한 번도 열지 않은 날은 기록되지 않습니다.
- **가챠 스케줄**은 기기 시드 + 날짜로 정해지므로 언제 열어도 같은 결과가 나옵니다.
- **조기 퇴근**: 퇴근시간 전에 퇴근하기를 누르면 그때까지의 진행률로 저장되고, 작업물은 미완성으로 남아 다음 근무일에 이어서 만듭니다. 퇴근 이후로 예정됐던 가챠는 사라집니다.
- **설정 변경**은 아직 퇴근하지 않은 오늘 기록과 이후 날짜에 반영되고, 지난 기록은 그날 스케줄을 그대로 유지합니다.
- 20개를 모두 완성하면 시즌 2가 시작되고, 사무실 화면에서 지난 시즌 사무실도 볼 수 있습니다.

## 구조

```
src/
  domain/        순수 로직 (테스트 대상)
    schedule.ts    근무시간·진행률·시급·햄스터 상태
    engine.ts      상태 동기화(reconcile), 퇴근, 설정 반영
    gacha.ts       가챠 이벤트 50종, 확률, 일일 스케줄
    workItems.ts   시즌 1 작업물 20개, 제작 단계
    records.ts     주간/월간 집계
    customization.ts 꾸미기 카탈로그·해금 조건
  components/    Hamster(SVG 애니메이션), WorkBuild, OfficeRoom, 모달
  screens/       Home, Office, Collection, Records, Customize, SettingsForm
  store.ts       localStorage 저장소 + 시계
  notify.ts      알림 (하루 3회 제한)
public/          manifest, 아이콘, 서비스워커
```

## 한계 (MVP)

- 웹 알림은 앱(탭)이 살아있을 때만 발송됩니다. 앱이 완전히 종료된 상태의 예약 알림은 네이티브 래핑(Capacitor 등)이나 푸시 서버가 필요합니다.
- 야간 근무(퇴근시간이 자정을 넘는 스케줄)는 지원하지 않습니다.
- 데이터는 기기에만 저장되며 백업/동기화는 없습니다.
