# 🐹 햄스터 출근일지

> 출근하고 그냥 켜두는 앱. 작은 햄스터가 화면 안을 스스로 돌아다니는 동안 번 돈이 실시간으로 쌓이고, 퇴근하면 하루가 저장된다.

모바일 우선 **PWA** (React + TypeScript + Vite). 휴대폰 브라우저에서 열고 "홈 화면에 추가"하면 앱처럼 설치되고 오프라인에서도 동작합니다. 모든 데이터는 기기(localStorage)에만 저장됩니다.

## 실행

```bash
npm install
npm run dev        # 개발 서버
npm test           # 도메인 로직 테스트 (vitest)
npm run build      # 타입체크 + 프로덕션 빌드 → dist/
npm run preview    # 빌드 결과 미리보기
```

시연용으로 URL에 `?t=2026-09-22T17:42` 를 붙이면 그 시각부터 시간이 흐릅니다 (예: `?t=2026-09-22T17:59:50` → 퇴근 연출).

## 햄스터의 하루

켜두기만 하면 햄스터가 근무 상태에 맞춰 알아서 움직입니다. 방에는 쳇바퀴·해바라기씨 그릇·솜 이불·책상이 있고,
창밖 하늘(아침/낮/노을/밤)과 벽시계는 실제 시각을 따라갑니다.

| 근무 상태 | 햄스터가 하는 일 |
| --- | --- |
| 출근 전 · 쉬는 날 | 솜 이불에서 쿨쿨 → 가끔 깨서 하품·세수, 씨앗 먹기 |
| 출근 | 솜 이불에서 일어나 하품·세수하고 책상으로 뽈뽈뽈, 손 흔들고 업무 시작 |
| 업무 중 | 책상에서 타자 치기, 쳇바퀴 돌기, 씨앗 먹기, 커피 홀짝, 세수, 여기저기 킁킁 탐색, 하품 (같은 일을 연달아 하지 않음) |
| 점심 | 씨앗 먹기 위주, 커피, 세수, 낮잠 |
| 퇴근 임박 | 타자 치다가 시계 보기, 서성이기 |
| 퇴근 1분 전 | 식은땀 흘리며 막판 스퍼트 |
| 퇴근 후 | 기지개 한 번 켜고 솜 이불로 가서 꿀잠 (가끔 깨서 하품·세수·간식) |

- **벽 선반**: 이번 시즌에 완성한 작업물이 햄스터 방 벽 선반에 하나씩 올라갑니다 (오늘 완성한 건 반짝).
- **번 돈 환산**: 오늘 번 돈이 붕어빵 → 커피 → 국밥 → 치킨 → … 값에 닿을 때마다 햄스터가 말풍선으로 알려줍니다.
- **희귀 행동**: 근무 중 아주 가끔(한두 시간에 한 번꼴) 볼주머니 빵빵·에취·창가에서 꾸벅꾸벅·쳇바퀴 멀미·혼자 추는 춤 중 하나를 합니다. 화면을 보고 있을 때 일어나면 도감에 등록됩니다.
- **월급날**: 급여일에 처음 열면 축하 화면(지난 월급날 이후 번 돈)이 뜨고, 그날 햄스터는 자주 춤을 춥니다.
- **출근 도장**: 퇴근하면 도장이 쾅 찍히고, 기록 탭에서 이번 주 도장과 월간 도장 달력을 볼 수 있습니다. 빠진 날에 벌칙은 없습니다.
- 이동은 미끄러지듯 움직이지 않고, 옆모습으로 다리를 번갈아 디디며 걷거나 **뽈뽈뽈 달리다 멈춰서 두리번거리는** 식으로 움직입니다.
- **탁상시계 모드**: 오늘 화면에서 폰을 가로로 눕히면 탭 메뉴가 사라지고 햄스터 방이 화면을 꽉 채우며, 옆에 번 돈·시각이 크게 나옵니다. 가로 화면인 동안엔 화면이 꺼지지 않고(지원 브라우저), 안드로이드는 ⛶ 버튼으로 전체 화면. 아이폰에서 주소창까지 없애려면 '홈 화면에 추가'로 설치해서 여세요.
- 햄스터를 톡 누르면 하던 일을 멈추고 손을 흔듭니다(자는 중이면 하품).
- 새로고침하거나 앱을 잠깐 닫았다 열어도(10분 이내) 햄스터가 하던 일과 위치를 이어갑니다. 보던 탭도 유지됩니다.
- 기록은 localStorage·IndexedDB·쿠키(설정만) 세 곳에 저장해서, 브라우저가 한 곳을 비워도 나머지에서 되살립니다. 주소 끝에 `?diag` 를 붙이면 저장 상태 진단 화면이 나옵니다.
- 시크릿 모드·쿠키 차단처럼 기록을 저장할 수 없는 브라우저나 카카오톡 등 앱 안 브라우저에서는 상단에 안내가 뜹니다.
- 개발용: `?gallery` 로 모든 자세를 한눈에, `?hspeed=3` 으로 햄스터 시간을 빠르게 볼 수 있습니다.

## 동작 규칙

- **실제 시간 기준**: 진행률·번 돈·가챠·퇴근은 모두 현재 시각으로 계산합니다(`src/domain/engine.ts`의 `reconcile`). 앱을 닫아 둬도 다음에 열면 그동안의 가챠와 퇴근이 한 번에 반영됩니다.
- **공휴일**: 대한민국 공휴일(설·추석 연휴, 대체공휴일, 선거일, 노동절 등 2025~2027년, `src/domain/holidays.ts`)은 쉬는 날로 처리합니다. 설정에서 끌 수 있습니다. 급여일이 주말·공휴일이면 전 영업일을 월급날로 봅니다.
- **하루 기록**은 근무일에 앱을 처음 연 날에 생성됩니다. 한 번도 열지 않은 날은 기록되지 않습니다.
- **가챠 스케줄**은 기기 시드 + 날짜로 정해지므로 언제 열어도 같은 결과가 나옵니다.
- **조기 퇴근**: 퇴근시간 전에 퇴근하기를 누르면 그때까지의 진행률로 저장되고, 작업물은 미완성으로 남아 다음 근무일에 이어서 만듭니다. 퇴근 이후로 예정됐던 가챠는 사라집니다.
- **설정 변경**은 아직 퇴근하지 않은 오늘 기록과 이후 날짜에 반영되고, 지난 기록은 그날 스케줄을 그대로 유지합니다.
- 20개를 모두 완성하면 시즌 2가 시작되고, 사무실 화면에서 지난 시즌 사무실도 볼 수 있습니다.

## 구조

```
src/
  domain/        순수 로직 (테스트 대상)
    schedule.ts    근무시간·진행률·시급·햄스터 상태
    engine.ts      상태 동기화(reconcile), 퇴근, 설정 반영
    gacha.ts       가챠 이벤트 50종, 확률, 일일 스케줄
    workItems.ts   시즌 1 작업물 20개, 제작 단계
    records.ts     주간/월간 집계
    customization.ts 꾸미기 카탈로그·해금 조건
  components/
    hamster/       햄스터 그림 (정면 앉은 자세 10종 + 희귀 행동 5종 + 옆모습 걷기/달리기/서기/자기), 털 윤곽 생성기
    habitat/       햄스터 사무실 소품, 행동 계획(brain), 실행 루프(Habitat)
    WorkBuild, OfficeRoom, Modals
  screens/       Home, Office, Collection, Records, Customize, SettingsForm
  store.ts       localStorage 저장소 + 시계
  notify.ts      알림 (하루 3회 제한)
public/          manifest, 아이콘, 서비스워커
```

## 한계 (MVP)

- 웹 알림은 앱(탭)이 살아있을 때만 발송됩니다. 앱이 완전히 종료된 상태의 예약 알림은 네이티브 래핑(Capacitor 등)이나 푸시 서버가 필요합니다.
- 야간 근무(퇴근시간이 자정을 넘는 스케줄)는 지원하지 않습니다.
- 데이터는 기기에만 저장되며 기기 간 백업/동기화는 없습니다.
