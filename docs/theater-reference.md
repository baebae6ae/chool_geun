# 썰 극장 연출 레퍼런스 — 「두햄빠!」 인스타 숏폼 분석

사용자가 화면 녹화로 보내 준 「두햄빠!」(IPX) 인스타 릴스 3편을 장면 단위로 뜯어 본 기록.
**연출 문법(구성·타이밍·카메라·장면 전환)만 배우고, 캐릭터 생김새나 특정 개그는 따라 하지 않는다.** (회사 캐릭터 IP)

---

## 1. 세 편 장면 분석 (시간은 녹화 기준 대략값)

### ① 소파 — "봐봐 이거 웃기지?" (약 20초)
| 시간 | 장면 | 연출 포인트 |
|---|---|---|
| 0~2초 | 흰 배경에 분홍 소파 하나. 왼쪽 햄스터는 누워서 폰 보며 깔깔, 오른쪽 토끼는 조용히 책 | **고정된 와이드 샷 하나 + 소품 하나**. 두 캐릭터 성격 대비(시끄러움 vs 조용함) |
| 2~5초 | 햄스터가 일어나 엉덩이로 **조금씩** 토끼 쪽으로 다가감 | 작은 이동을 여러 번 끊어서 = 기대감 쌓기 |
| 5~9초 | 바짝 붙어서 폰을 들이밀고 반짝이(✨)를 뿜으며 들썩들썩 | **반복·점층**: 같은 동작을 계속 → 귀찮음이 쌓임 |
| 9~11초 | 토끼 얼굴 클로즈업. 무표정으로 폰을 봄, 눈만 깜빡 | **리액션 컷 + 정지(홀드)**: 웃음이 터지는 자리. 2초 가까이 아무 일도 안 일어남 |
| 11~13초 | 다시 와이드. 햄스터 기대에 찬 얼굴, 토끼 무반응 | 같은 화면으로 돌아와 대비 |
| 13~15초 | 갑자기 **잿빛 갈라진 황무지**에 햄스터 혼자 조그맣게 → 노란 빛줄기 속에 **새까만 실루엣**이 됨 | **속마음을 장소로 바꿔 보여 주기**(시각적 과장). 글자 없이 "충격/허무"를 전달 |
| 15~20초 | 소파로 복귀. 햄스터 폰 툭 떨어뜨리고 토끼에게 기대어 붙음 | 현실 복귀 + 허무한 마무리. 다시 처음 화면이라 **반복 재생해도 자연스러움** |

### ② 바닥 — "나 대신 일해 줄 분신이 있다면" (약 17초)
| 시간 | 장면 | 연출 포인트 |
|---|---|---|
| 0~1초 | 오리가 바닥에 납작 엎드려 있고, 머리 위에 **생각 풍선** | 상상과 현실을 한 화면에 나눔 |
| 1~3초 | 풍선 안에 오리 1 → 3 → 5마리로 **복제** | 셋 법칙·점층 |
| 3~6초 | 분신들이 노트북 업무, 청소, 깃발 응원 등 **각자 일을 맡음** | 상상이 구체적일수록 웃김 |
| 6~7초 | 풍선 속에 **눈부신 후광**과 함께 지팡이 든 현자 등장 → 풍선이 펑 | 갑자기 커지는 과장 → 상상이 현실로 넘어오는 전환 |
| 7~11초 | 현실에 현자와 분신들이 우르르 나타남 | 풍선 → 현실로 **경계 넘기** |
| 11~17초 | 분신들도 하나둘 원래 오리처럼 **바닥에 납작 엎드림** | **반전 펀치라인**: 분신도 나처럼 게으르다. 끝 장면이 첫 장면과 운이 맞음 |

### ③ 침실 — "5분만 더" (약 30초)
| 시간 | 장면 | 연출 포인트 |
|---|---|---|
| 0~4초 | **창밖에서** 본 밤의 방. 오리가 이불 속에서 잠 | **설정 샷**(밖 → 안). 차분한 파란 색조 |
| 4~6초 | 방 안 와이드. 폰이 반짝 | |
| 6~8초 | **폰 잠금화면 인서트** 6:05 → 6:06 | 시간을 글자 자막이 아니라 **소품 화면**으로 알려 줌 |
| 8~11초 | 부스스 일어나 앉음 | |
| 11~15초 | 흰 배경 미니 세트로 **몽타주**: 샤워 → 화장대 | 루틴은 짧게 끊어서 빠르게 |
| 15~19초 | 침대에 다시 앉아 폰 보며 커피 / 잠금화면 7:15 → 7:16 | 같은 인서트를 반복해서 시간 흐름을 보여 줌 |
| 19~23초 | 다시 눕더니 웅크림. **방이 점점 어두워짐 → 완전 암전** | 조명 변화 = 시간이 흐르고 잠듦 |
| 23~25초 | 잠금화면 **11:15** | 반전 정보를 인서트 한 장으로 |
| 25~30초 | 방이 **하얗게 날아갈 듯 밝고**, 화면이 휙휙 **흔들리며 번짐**. 벌떡 일어나다 커피잔이 바닥에 와장창 | 패닉은 카메라 번짐·흔들림으로. **사고(충돌) 순간에서 뚝 끝남** |

## 0. 우리 썰 극장에 가져오는 것 / 안 가져오는 것 (결정)

| 항목 | 결정 |
|---|---|
| 글자·자막 | **안 따라 함.** 단어가 튀어나오는 키네틱 자막은 지금처럼 쓴다 |
| 작은 캐릭터 + 넓은 배경 | **가져옴.** 기본 샷은 캐릭터가 작고 배경이 넓게 보이게 |
| 고정 카메라 | **안 따라 함.** 카메라는 계속 움직인다 (천천히 다가가기, 옆으로 따라가기, 확 당기기) |
| 타이밍 개그 (리액션 정지, 반복·점층) | **가져옴** |
| 속마음을 장소로 과장 (황무지, 실루엣, 생각 풍선, 후광) | **가져옴** |
| 시간을 소품·조명으로 (폰 잠금화면, 시계, 점점 어두워짐·암전, 과하게 밝음) | **가져옴** |
| 이야기 구조 | **안 따라 함.** 스토리는 우리가 짠다. 연출만 가져온다 |
| 뚝 끝내기·반복 재생 | **필요 없음** |

## 2. 공통 연출 원칙 (분석 기록)

1. **글자·대사가 거의 없다.** 상황은 소품(폰 화면, 시계, 생각 풍선)과 표정, 몸짓으로 전달한다. 자막 대신 **인서트 샷**을 쓴다.
2. **화면은 단순하게.** 흰 배경이나 단색 배경에 핵심 소품 하나(소파, 침대)만 둔다. 캐릭터는 화면에 비해 작고 여백이 넓다.
3. **카메라는 거의 고정, 대신 컷을 바꾼다.** 기본은 와이드 고정 샷이고, 웃음 포인트에서만 클로즈업 리액션으로 넘어간다. 줌이나 팬보다 **컷 전환**이 중심이다.
4. **타이밍이 개그다.** 리액션 컷은 1.5~2초 동안 **아무 일도 일어나지 않게** 둔다. 작은 동작은 여러 번 끊어서 반복하고 점점 키운다.
5. **속마음은 장소나 상상으로 과장한다.** 황무지에 혼자 남기, 새까만 실루엣, 생각 풍선, 후광처럼 감정을 현실이 아닌 그림으로 바꿔 보여 준다.
6. **시간은 소품과 조명으로 보여 준다.** 잠금화면 시각, 방이 어두워지다 암전, 과하게 밝아진 아침 같은 방식이다.
7. **구조는 [평온 → 작은 욕심/행동 → 반복·점층 → 과장(상상) → 현실 복귀 + 허무한 반전]**이고, 15~30초 안에 끝난다.
8. **끝은 뚝.** 충돌이나 반전 순간에 바로 끝나거나 첫 장면으로 돌아와서, 반복 재생이 자연스럽다.
9. **움직임은 작고 귀엽게.** 들썩들썩, 조금씩 다가가기, 반짝이 같은 효과 정도이고, 큰 액션은 클라이맥스 한 번뿐이다.
10. **소재는 거창한 사건이 아니라 "아 나도 저래" 하는 일상의 한 장면**이다.

## 3. 지금 썰 극장 시안과 비교

| 지금 시안 (wip/theater) | 레퍼런스 |
|---|---|
| 단어가 튀어나오는 자막, 효과음 글자 많음 | 글자 거의 없음 |
| 웹툰 컷 분할, 글리치, 망점, 흔들림을 자주 씀 | 단순한 고정 샷 + 필요한 순간에만 컷 전환 |
| 매 컷이 바쁘고 정보가 많음 | 여백과 정지(홀드)가 많음 |
| 시각을 자막 스티커로 알려 줌 | 시각을 폰·시계 인서트로 보여 줌 |

→ 앞으로 썰 극장은 **"말 없이도 웃기는" 쪽으로 덜어 내는 것**이 목표다.

## 4. 썰 극장에 필요한 연출 도구 (엔진에 추가할 것)

- **인서트 샷**: 폰 잠금화면(시각·알림), 벽시계, 메신저 화면을 화면 가득 보여 주는 컷
- **생각 풍선**: 풍선 안에 작은 장면을 넣고, 풍선이 펑 터지며 현실로 넘어오는 전환
- **복제·점층**: 같은 캐릭터를 1 → 3 → 5로 늘리기
- **상상 배경**: 황무지(허무), 후광·빛줄기(깨달음/신), 비 오는 먹구름(우울), 우주(멍) 같은 감정 장소
- **실루엣 변신**: 캐릭터가 새까맣게 되거나, 색이 빠지는 충격 표현
- **조명 변화**: 서서히 어두워짐 → 암전, 과하게 밝아짐(늦잠 패닉)
- **설정 샷**: 건물·창밖에서 시작해서 안으로 들어오기
- **리액션 홀드**: 클로즈업 무표정 + 눈 깜빡임만 있는 1.5~2초 정지 컷
- **조금씩 다가가기**: 한 번에 이동하지 않고 끊어서 3~4번 들썩이며 이동
- **패닉 번짐**: 화면 전체 움직임 번짐 + 흔들림 (클라이맥스 한 번만)
- **와장창 마무리**: 소품 떨어뜨려 깨지는 순간에 뚝 끝내기

## 5. 직장 썰에 적용하는 예

- **5분 회의**: 회의실 고정 샷 → 벽시계 인서트 14:00 → 같은 샷 (사람들 자세만 조금씩 무너짐) → 시계 인서트 16:47 → 내 얼굴 리액션 홀드(무표정, 눈 깜빡) → 황무지에 혼자 → 회의실 복귀, 팀장 "다음에 다시" 손짓 → 뚝
- **Ctrl+S**: 책상 고정 샷, 타다닥 들썩들썩 → 모니터 인서트 "응답 없음" → 내 얼굴 리액션 홀드 → 새까만 실루엣 → 책상 복귀, 노트북 조용히 덮고 엎드림 → 뚝
- **퇴근 10분 전**: 폰 잠금화면 17:50 인서트 → 신나서 조금씩 문 쪽으로 다가가기 → 문 열리고 팀장 → 생각 풍선에 칼퇴하는 나(분신들이 춤) → 풍선 펑 → 자리로 돌아가 앉음 → 잠금화면 19:40 → 뚝

## 6. 지킬 것

- 캐릭터·배경·특정 개그 장면을 그대로 옮기지 않는다. 우리 캐릭터(햄찌·토끼·오목눈이·고양이)와 직장 소재로 새로 만든다.
- 배경 음악은 쓰지 않는다 (저작권). 대신 타이밍과 진동으로 박자를 준다.
