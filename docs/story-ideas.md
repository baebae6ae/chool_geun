# 썰 극장 콘티 후보

직장인 커뮤니티·공감 짤에서 자주 나오는 소재(회식, 야근, 퇴근 직전 업무, 밤 9시 팀장 카톡, 점심 메뉴,
만원 엘리베이터, 광고주 수정 지옥, 출근 직후 화장실 경쟁 등)를 바탕으로 짠 썰 후보.
확정: 사용자 피드백 반영(18·30 삭제). 형식: **상황 → 꼬임 → 펀치라인**. 재료 표시: ✅ 지금 있는 배경·동작으로 가능 / 🎨 새 그림 필요(앱 업데이트 필요).
기존 4편: 5분이면 끝나는 회의, 저장 버튼의 소중함, 퇴근 10분 전의 그림자, 탕비실 푸딩 실종 사건.

진행: ✅ 23편은 `src/content/stories.json`에 썰 #5~#27로 들어감 (앱 업데이트 없이 웹으로 배포).
🎨 6편(3, 4, 9, 11, 26, 29)은 새 그림을 그린 뒤 앱 업데이트와 함께.

## 출근길·아침
1. **닫힘 버튼** ✅ — 지각 직전 엘리베이터로 전력 질주 → 문이 닫히는데 안에 있던 사람과 눈이 마주침 → 그 사람이 '열림' 대신 '닫힘'을 꾹. 문틈으로 보이는 썩은 미소.
2. **월요병** ✅ — 일요일 밤 11시 폰 잠금화면 → (암전) → 월요일 아침 지하철에 영혼만 탑승 → 회사 건물 앞에서 실루엣. "월요일은 *왜 매주* 와요?"
3. **지문 인식 3초 전** 🎨 — 8:59:57, 출입 단말기 "다시 시도하세요" ×3 → 9:00. (단말기 소품 필요)
4. **9시 5분 화장실 전쟁** 🎨 — 출근하자마자 화장실, 칸마다 다 잠김 → 칸 안에서 들리는 '떡상 가즈아', '물렸다…' 주식 중계 → 주인공 "난 진짜 똥이라고!!!" (화장실 배경 필요)

## 오전 업무
5. **전체 회신** ✅ — 동기에게 "팀장님 오늘 기분 별로임ㅋㅋ" 답장 → 화면 인서트 '전체 회신으로 보냈습니다' → 황무지 실루엣 → 팀장님 답장 "ㅎㅎ"
6. **마이크 켜져 있어요** ✅ — 화상회의 중 음소거인 줄 알고 노래 → 채팅창에 'ㅋㅋㅋ'가 우르르 쌓임 → 모니터 '마이크가 켜져 있습니다' → OTL
7. **느낌 있게 해 주세요** ✅ — "좀 더 느낌 있게요" → 파일명 최종 → 진짜최종 → v27 (숫자 촤라락) → "그냥 처음 거로 할게요" → 영혼 이탈
8. **반려** ✅ — 밤새 만든 보고서 결재 → 도장 '반려' 쾅 → 사유: "제목에 '최종'이 들어가서 불길함"
9. **프린터 용지 걸림** 🎨 — 회의 5분 전 '용지 걸림' → 낑낑대며 빼려는데 안 빠짐 → IT팀 호출 → IT팀이 인쇄 버튼만 누름 → 정상 작동. (프린터 필요)

## 점심
10. **아무거나요** ✅ — "점심 뭐 먹을래?" "아무거나요" → 김치찌개? "어제 먹었는데" 돈가스? "무거운데" … 메신저가 쌓임 → 12:58 시계 → 편의점
11. **식곤증 오후 2시** 🎨 — 꾸벅꾸벅, 생각 풍선 속 침대 → 등 뒤에 팀장님 그림자 → 눈 감고 생각하는 척 → 전구 번쩍 + 검지 척 "아하!!" (전구 이펙트·검지 동작 필요)
12. **원두 소진** ✅ — 탕비실 커피 줄 → 내 앞사람이 마지막 잔 → 커피머신 '원두를 채워 주세요' → 먹구름 비
13. **점심시간 1분 전 엘리베이터** ✅ — 12:59 엘리베이터 만원 '띵— 정원 초과' → 계단으로 13층 → 13:00 도착 실루엣

## 상사·동료
14. **칭찬의 대가** ✅ — "역시 잘하네~" 후광 → "이것도 해 볼래?" → 업무 3개 → 9개 (숫자 촤라락) → 생각 풍선 분신 5명도 모자람
15. **내가 언제 그랬어** ✅ — 시킨 대로 했더니 "누가 이렇게 하랬어?" → 메신저 캡처 인서트 → 팀장님 "아 그건 그때고"
16. **대표님과 엘리베이터 단둘이** ✅ — 문 닫힘 → 층수 1F…2F…(엄청 느림) → 정적 → 대표님 "몇 년차지?" → 동공 지진 → "21년식 아반떼입니다!!!" → 우주 배경(멍)
17. **밤 9시 카톡** ✅ — 침대에서 쉬는데 잠금화면 '팀장님: 자니?' → 동공 지진 → 읽씹할까 말까 생각 풍선 → '아 아니야 내일 얘기하자' → 잠이 안 옴
19. **눈치 야근** ✅ — 6시, 아무도 안 일어남 → 다들 팀장님만 봄 → 팀장님은 유튜브 보는 중 → 9시 팀장님 퇴근하자 전원 동시 기립

## 회식
20. **건배사 20분** ✅ — "짧게 한마디만" → 시계 인서트 20분 → 잔 든 팔이 덜덜 → 다들 영혼 이탈 → "자 그럼 건배!" (회식 배경이 있으면 더 좋음 🎨)
21. **2차 탈출** ✅ — 몰래 빠져나가 지하철역까지 들썩들썩 → 폰 '부장님: 어디야~ 너 지갑 놔두고 갔다~' → 먹구름
22. **회식 다음 날** ✅ — 출근했는데 다들 웃음 → 단톡방 사진 알림 → 실루엣 → "기억이… 없어요"

## 월급·돈
23. **스쳐 가는 월급** ✅ — 잠금화면 '급여 입금 3,000,000원' 후광 → 카드값·월세·통신비·적금 알림 연속 → 잔액 3,000,000 → 12,400 (숫자 촤라락) → 황무지
24. **13월의 월급?** ✅ — 연말정산 기대 후광 → '추가 납부 340,000원' → 실루엣

## 연차·주말·퇴근
25. **연차 신청** ✅ — "다음 주 금요일 연차 써도 될까요?" → "그날은 좀…" → 월요일은? "그날도 좀…" → 먹구름
26. **연차 중 업무 연락** 🎨 — 바닷가에서 노는데 물속에서 팀장님이 인자한 미소로 쑥 → "김대리 쉬는데 미안한데 이것좀~" (바다 배경·물에서 등장 필요)
27. **금요일 6시** ✅ — 17:59 시계 → 18:00 땡 → 엘리베이터까지 질주(잔상) → 후광 받으며 지하철 → 토요일 반짝이
28. **지하철 자리 쟁탈** ✅ — 빈자리 발견 → 들썩들썩 다가가는데 옆 사람이 쏙 → 동공 지진 → 손잡이와 하나 됨
29. **퇴근 후 운동 결심** 🎨 — "오늘은 진짜 헬스" → 집 도착 → 침대에 눕는 순간 우주 → 다음 날도 반복 (집 배경 필요)
