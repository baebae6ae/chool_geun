# Play Console 프로덕션 액세스 신청 답변 초안

비공개 테스트: 테스터 12명, 14일 완료. 실제 질문 문구는 조금 다를 수 있으니 맞는 칸에 골라 넣는다.
[ ] 칸은 직접 채운다.

## 테스터는 어떻게 모았나요?
지인과 직장인 지인들을 중심으로 12명을 모았습니다. 앱이 직장인의 출퇴근 일상을 다루는 앱이라,
실제로 회사에 다니는 분들 위주로 모집했습니다. [모집할 때 어려웠던 점: ]

## 피드백은 어떻게 받았고, 어떤 내용이었나요?
[메신저/직접 대화 등]으로 피드백을 받고, 직접 매일 앱을 쓰면서 불편한 점을 기록했습니다. 주요 피드백:
- 업무 중에 오는 가짜 대화가 재미없다
- 공휴일이 끼면 주차별 결과물이 다음 주로 밀린다
- 이벤트 아이템을 받았는데 어떻게 쓰는지 모르겠다
- 시간이 지날수록 홈 화면 방이 어지러워진다
- 짧은 이야기를 본 뒤 홈 화면 시계 위치가 틀어진다

## 테스트 결과를 보고 무엇을 바꿨나요?
- 업무 중 대화 77개를 새로 쓰고, 답장 연출을 더 시원하게 바꿨습니다.
- 결과물을 주차 단위 대신 파트 단위로 바꿔서, 공휴일이나 연차가 있어도 끊기지 않게 했습니다.
- 이벤트 화면에 출석 도장과 「써 보기」 버튼을 넣고, 아이템을 받는 날 알림을 띄웠습니다.
- 홈 화면 방에는 오늘 완성한 결과물만 두고, 지난 결과물은 사무실 탭에서 보게 정리했습니다.
- 퇴근하면 짧은 직장인 이야기 애니메이션 「오늘의 썰」을 볼 수 있게 추가했습니다(33편). 새 이야기는 앱 업데이트 없이 받아옵니다.
- 앱을 업데이트한 뒤 처음 켤 때 새 기능 안내창이 뜨게 했습니다.
- 화면 배치 버그를 고쳤습니다.

## 출시할 준비가 됐다고 판단한 이유는요?
테스트 기간 동안 [ ]번 업데이트하며 피드백을 반영했고, 주요 기능(출퇴근 기록, 월급 계산, 꾸미기, 이벤트,
오늘의 썰)이 안정적으로 동작하는 것을 확인했습니다. 서버 없이 기기 안에서만 동작해서 개인정보를 따로 수집하지 않습니다.
