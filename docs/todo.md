# 해야 할 것 (정식 출시 전)

제보 화면·응원 화면은 앱에 만들어 둠. 아래를 사장님이 준비하면 연결만 하면 된다.

## 1. 제보용 Google 폼 (사장님) — ✅ 연결 완료 (src/domain/report.ts)
1. Google 폼 새로 만들기, 제목: 햄스터 출근일지 제보
2. 질문 4개 (이 순서·이 글자 그대로)
   - 객관식 「제보 종류」: `어이없는 업무 대화` / `직장 썰`
   - 장문형 「내용」
   - 단답형 「크레딧 이름」 (필수 아님)
   - 체크박스 「동의」: `동의합니다` (필수)
3. 설정 → 응답 → 「이메일 주소 수집」 끄기, 「로그인 필요」 끄기
4. 오른쪽 위 ⋮ → 「미리 채워진 링크 가져오기」 → 아무 값이나 채우고 「링크 받기」 → 그 링크를 Claude에게 전달
   (링크 안의 `entry.숫자`로 앱이 폼에 바로 보낸다)
→ Claude: `src/domain/report.ts`의 `REPORT_FORM`에 채우고, 개인정보처리방침에 제보 문단 추가

## 2. 응원(후원) 인앱 상품 (사장님)
1. Play Console → 설정 → 결제 프로필(판매자) 등록: 은행 계좌·세금 정보
2. 앱 → 수익 창출 → 제품 → 인앱 상품 → 3개 만들기 (ID는 이 글자 그대로, 만든 뒤 「활성화」)
   - `tip_coffee` 아아 한 잔 1,500원
   - `tip_cake` 케이크 한 조각 5,000원
   - `tip_chicken` 치킨 반 마리 10,000원
3. 테스트: 설정 → 라이선스 테스트에 본인 Gmail 추가하면 실제 결제 없이 시험 구매 가능
→ 상품만 활성화되면 앱은 그대로 동작 (가격은 스토어 가격을 받아 와 표시)
→ 데이터 보안 양식: 「구매 기록」 항목 확인 필요 (결제는 Google Play가 처리)
