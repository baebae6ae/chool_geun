# 썰 극장 애니메이션 기법 목록

썰 극장이 "그냥 말풍선 넘기기"가 아니라 진짜 짧은 애니메이션처럼 보이게 하려고 쓰는 기법들.
디즈니의 애니메이션 12원칙(Frank Thomas · Ollie Johnston, 『The Illusion of Life』, 1981),
일본 애니메이션·만화 연출, 영상 편집의 카메라·전환 기법에서 골랐다.
"구현"은 이 앱(React + CSS + SVG)에서 어떻게 만드는지, "쓰임"은 썰에서 언제 쓰는지.

## 1. 움직임의 기본 (애니메이션 12원칙)

| 기법 | 설명 | 구현 | 쓰임 |
|---|---|---|---|
| 스쿼시 & 스트레치 | 눌릴 때 납작, 뛸 때 길쭉. 부피는 그대로 | 캐릭터 감싸는 div에 `scale(1.15, 0.85)` ↔ `scale(0.9, 1.12)` 키프레임 | 깜짝 놀라 뛰기, 착지, 털썩 주저앉기 |
| 예비 동작 (Anticipation) | 큰 동작 전에 반대로 살짝 움츠림 | 점프 전 0.15초 납작하게 웅크렸다가 튀어 오름 | 뛰쳐나가기, 책상 쾅 직전 |
| 연출 (Staging) | 지금 중요한 것 하나만 눈에 띄게 | 스포트라이트(주변 어둡게), 카메라 줌, 중요한 캐릭터만 움직이기 | 팀장 등장, 반전 순간 |
| 천천히 시작·끝 (Slow in/out) | 움직임은 서서히 빨라지고 서서히 멈춤 | 이동·카메라에 `cubic-bezier` 이징 | 모든 이동과 카메라 |
| 곡선 궤적 (Arcs) | 생물의 움직임은 직선보다 곡선 | 점프를 위로 볼록한 경로(키프레임 여러 개)로 | 점프, 던지기 |
| 따라오는 동작 (Follow-through) | 몸이 멈춰도 귀·꼬리·말풍선은 조금 더 흔들림 | 멈출 때 살짝 지나쳤다 돌아오는 오버슈트 이징 | 말풍선 등장, 급정지 |
| 보조 동작 (Secondary action) | 주 동작에 곁들인 작은 동작 | 땀방울, 김, 반짝이, 소품 흔들림 | 당황, 분노, 기쁨 |
| 타이밍 | 프레임 수(시간)가 무게와 감정을 만듦 | 빠른 동작은 0.1~0.2초, 여운은 1초 이상 정지 | 개그 타이밍, "…" 침묵 |
| 과장 (Exaggeration) | 실제보다 크게 | 비율 큰 줌, 크게 튀는 반응, 만화 기호 | 충격, 분노 |
| 매력 (Appeal) | 보고 싶은 캐릭터 | 기존 캐릭터 그대로(짧은 팔 비율 유지) | 전부 |

## 2. 일본 애니메이션 · 만화 연출

| 기법 | 설명 | 구현 | 쓰임 |
|---|---|---|---|
| 집중선 (集中線) | 화면 가장자리에서 중심으로 모이는 선 | 원 둘레에서 중심으로 향하는 SVG 선, 깜빡이며 회전 | 충격, 등장, 깨달음 |
| 속도선 (Speed lines) | 빠르게 지나가는 가로선 | 가로 줄무늬가 흘러가는 배경 레이어 | 미친 듯이 타자, 질주 |
| 임팩트 프레임 | 부딪히는 순간 1~2프레임 반전·섬광 | 화면 흰색 섬광 → `invert` 한 번 → 원래대로 (총 0.15초) | 쾅!, 충격 대사 |
| 히트 스톱 (Hit-stop) | 맞는 순간 잠깐 멈춤 | 무대의 모든 CSS 애니메이션 `paused` 0.1~0.3초 | 문 쾅, 등장 순간 |
| 스미어 · 잔상 | 빠른 동작을 번진 그림으로 | 이동 중 `blur` + 뒤따라오는 반투명 잔상 2개(전환 시간을 조금씩 늦게) | 순간이동하듯 달려오기 |
| 만화 기호 (漫符) | 땀방울(당황), 💢 핏줄(분노), 세로 그늘선(좌절), ?, !, 반짝이 | 캐릭터 머리 옆에 SVG 기호가 톡 튀어나옴 | 감정 표현 전부 |
| 석화 (石化) | 너무 놀라 돌이 됨 | 회색 필터 + 금이 가는 선 + 미세 떨림 | 퇴근 직전 팀장 |
| 효과음 글자 (의성어) | 화면에 크게 쓰는 "쾅!", "두둥" | 테두리 두꺼운 큰 글자가 회전하며 튀어나옴 | 문 열림, 충격, 털썩 |
| 홀드 (Hold) | 표정 그대로 멈춰 있는 개그 | 다음 장면까지 일부러 1초 넘게 정지 | "…네." 직전 |

## 3. 카메라

| 기법 | 설명 | 구현 | 쓰임 |
|---|---|---|---|
| 푸시 인 (천천히 다가가기) | 감정이 고조될 때 서서히 확대 | 무대 `scale` 1 → 1.6, 2~3초 | 절망, 깨달음 |
| 크래시 줌 (Crash zoom) | 순간적으로 확 당겨 확대 | `scale` 1 → 2.2, 0.15초 | "!!!" 충격 |
| 팬 (Pan) | 시선을 옆으로 옮김 | 무대 `translate` 이동 | 문 쪽으로 시선 이동 |
| 기울인 앵글 (Dutch angle) | 화면을 기울여 불안감 | 무대 `rotate(-6deg)` | 불길한 등장 |
| 카메라 흔들림 | 충격이 화면까지 전달 | 무작위 이동 키프레임, 세기 3단계 | 쾅, 등장 |
| 스포트라이트 · 비네트 | 주인공 주변만 밝게 | 화면 위 원형 그라데이션 어둠 | 등장, 독백 |
| 슬로모션 | 결정적 순간을 늘림 | 그 장면의 동작 시간을 2~3배로 | 클라이맥스 |

## 4. 장면 전환 · 편집

| 기법 | 설명 | 구현 | 쓰임 |
|---|---|---|---|
| 타이틀 카드 | 검은 화면에 제목 | 검은 판 + 타자기 효과 글자 | 썰 시작 |
| 레터박스 | 위아래 검은 띠로 영화 느낌 | 시작할 때 띠가 미끄러져 들어옴 | 썰 전체 |
| 프리즈 프레임 | "그때까지만 해도 몰랐다…" | 화면 정지 + 세피아 + 자막 | 복선, 회상 |
| 타임랩스 | 시간이 훅 지나감 | 시계 바늘 빨리 돌기 + 창밖 하늘 색 변화 + "2시간 후" | 끝나지 않는 회의 |
| 아이리스 아웃 | 동그랗게 닫히며 끝 | `clip-path: circle()`이 캐릭터 얼굴로 좁혀짐 | 썰 끝 |
| 자막 (내레이션) | 상황 설명 | 아래쪽 자막 타자기 효과 | 상황 설명 |
